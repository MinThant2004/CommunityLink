2. DETAILED FEATURE BACKLOG & WORK COMPLETED
--------------------------------------------------------------------------------

[FEATURE 1] Telegram-Style Shareable Invite Links System
--------------------------------------------------------------------------------
- Database Layer:
  * Created `TblChatGroupInviteLink` entity & DDL migration script with indexes 
    for unique URL tokens (`UQ_TblChatGroupInviteLink_Token`) and single active 
    primary links per group (`UQ_TblChatGroupInviteLink_Primary`).
  * Implemented `ChatGroupInviteLinkDatabaseSeeder.cs` for automated setup.

- Backend & Domain Service:
  * Added `GetOrCreatePrimaryInviteLinkAsync`: Auto-generates a primary invite link 
    for every chat group.
  * Added `GetInviteLinksAsync`: Fetches all active invite links for Group Owners & Admins.
  * Added `CreateInviteLinkAsync`: Allows creation of custom invite links with optional 
    link names, expiration dates, and usage caps.
  * Added `RevokeInviteLinkAsync`: Enables revoking active invite links.
  * Added `GetInviteLinkPreviewAsync`: Public unauthenticated preview endpoint for group metadata.
  * Added `JoinViaInviteLinkAsync`: Authenticated join handler with ban checking, 
    duplicate join guards, and system message dispatch.

- API & Client Layer:
  * Exposed REST endpoints in `ChatGroupController.cs` under `/api/chat-groups/...`.
  * Added client methods in `ChatGroupApiService.cs`.

- Frontend & UI (Blazor App):
  * Integrated "Invite link" quick action button and "Invite links" settings row with 
    active link count badge in `ChatThreadInfoPanel.razor`.
  * Designed Telegram-style "Invite links" Modal Box featuring:
    - Primary link card displaying full URL.
    - "Copy Link" & "Share Link" action buttons with clipboard feedback.
    - "+ Create a New Link" section for custom named invite links.
    - List of active custom links with usage counts and revoke controls.
  * Created Public Invite Landing Page (`InviteJoin.razor` at `/invite/{Token}`):
    - Displays Group Avatar, Name, Description, Member Count, and Free/Paid badge.
    - Paid Group Join: Integrates `<UnlockChatModal>` with wallet balance check 
      (`LinkDropApiService`), allowing users to confirm payment and join seamlessly.

[FEATURE 2] Dedicated Confirmation Modal Boxes
