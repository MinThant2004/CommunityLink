DETAILED BACKLOG DELIVERABLES & USER STORIES
--------------------------------------------------------------------------------

[TICKET-1] Premium Membership Upgrade Purchase Flow & Direct Modal Trigger
- Context & Problem:
  On the /upgrade page, the bottom action buttons for subscription tiers (Domain 
  Pro and Public Figure VIP) previously redirected users away to the LinkDrops 
  wallet top-up page instead of initiating the plan checkout sequence.
- Implementation:
  * Modified the plan action handlers in Upgrade.razor to open the checkout and 
    escrow verification modal directly for the selected plan.
  * Preserved wallet sufficiency checks and escrow calculation logic inside 
    the modal, allowing users to inspect costs, balance offsets, and escrow terms 
    before completing the purchase.
- Key Files: Components/Pages/Upgrade.razor
- Acceptance Criteria: Users can initiate and submit a tier upgrade application 
  directly without extraneous page hops.

[TICKET-2] Role-Based Navigation Architecture (Navbar vs. Sidebar)
- Context & Problem:
  Navigation controls were cluttered and did not differentiate workspace layouts 
  between standard community members and verified premium/admin operators.
- Implementation:
  * Default Users ('USER'): Sidebar (<aside>) is completely hidden. Primary navigation 
    is handled exclusively via a lightweight top navigation bar for focused feed browsing.
  * Premium & Admin Users ('DOMAIN_PRO', 'PUBLIC_FIGURE', 'ADMIN', Active Subscription): 
    Left sidebar (<NavMenu />) is displayed with full management links. Top navbar 
    navigation links are hidden to provide a clean, uncluttered workspace.
  * Added dynamic subscription status evaluation via UpgradeApi.GetMyStatusAsync() 
    during layout initialization, ensuring users who become approved immediately 
    see the sidebar without requiring a manual logout/relogin.
- Key Files: Components/Layout/MainLayout.razor, Apis/SubscriptionUpgradeApiService.cs
- Acceptance Criteria: Layout automatically switches dynamically based on live 
  user role and subscription status.

[TICKET-3] Top Navigation Bar UX Polish & Layout Optimization
- Context & Problem:
  The top navigation bar showed horizontal scrollbars on certain screen sizes, 
  contained a standalone logout button, and featured duplicate LinkDrop links.
- Implementation:
  * Logout Relocation: Relocated the authenticated logout form into the profile 
    dropdown card hidden beneath the user avatar button.
  * Zero Scrollbars: Added utility classes ([scrollbar-width:none] [-ms-overflow-style:none] 
    [&::-webkit-scrollbar]:hidden) to ensure horizontal scrolling remains functional 
    on touch devices while completely hiding scrollbar tracks.
  * Deduplication: Removed duplicate cartoon LinkDrop link from the top navigation 
    links, leaving the dedicated balance indicator as the single point of access.
- Key Files: Components/Layout/MainLayout.razor
- Acceptance Criteria: Navbar is scrollbar-free, logout is securely nested in 
  profile menu, and duplicate links are removed.

[TICKET-4] Platform-Wide Dark & Light Mode System Unification
- Context & Problem:
  Several administrative, creator, and community pages lacked proper Tailwind dark: 
  mode classes, resulting in glaring white cards or unreadable contrast in dark mode.
- Implementation:
  * Updated AdminLayout.razor with dark background tokens (dark:bg-[#0A0D14], 
    dark:bg-[#111927], dark:border-[rgba(196,210,225,0.12)]) and an interactive theme 
    toggle button.
  * Extended dark: tokens across all 11 Admin management pages (Plans, Verifications, 
    LinkDrops, Dashboard, Communities, Users, Accounts, Finance, Payouts, AuditLogs, Settings).
  * Harmonized dual themes across Creator views (Earnings, Payouts), Community 
    views (GroupDetail, Communities, PostUpload, Polls), Member views (UserProfile, 
    UserDashboard, Activity), and Layout components (ToastContainer, NotificationBell).
- Key Files: AdminLayout.razor, Admin*.razor, Creator*.razor, GroupDetail.razor, 
  ToastContainer.razor, Activity.razor, NotificationBell.razor
- Acceptance Criteria: All pages transition seamlessly between dark and light themes 
  with optimal contrast and zero unstyled containers.

[TICKET-5] UI Modernization: Complete Removal of Cartoon Emojis
- Context & Problem:
  Platform pages, buttons, badges, and modals utilized cartoon Unicode emojis 
  (e.g., water drops, emojis, skulls, crowns, trashcans), compromising the 
  professional aesthetic of the application.
- Implementation:
  * Systematically audited and replaced all cartoon emojis across all layouts, 
    admin tables, action buttons, activity feeds, and verification flows with 
    curated SVG vector icons and Material Symbols.
  * Maintained user interactive reaction pickers (TelegramEmojis in chat) as 
    functional user input components while upgrading all static platform UI icons.
- Key Files: NavMenu.razor, Activity.razor, GroupDetail.razor, AdminPlans.razor, 
  AdminVerifications.razor, UserRegister.razor, UserLogin.razor, ToastContainer.razor
- Acceptance Criteria: 100% of platform UI icons utilize modern, scalable vector graphics.

[TICKET-6] LinkDrop Digital Currency Rebranding (Hexagonal Security Chip)
- Context & Problem:
  LinkDrop virtual currency utilized generic waterdrop icons across the platform, 
  conflicting with its positioning as an escrowed, cryptographic community utility token.
- Implementation:
  * Designed and implemented a custom Hexagonal Security Chip vector graphic featuring 
    beveled metallic gradients, cryptographic nexus value-flow arms, and micro-notches.
  * Built a reusable Blazor component (<LinkDropIcon />) with unique dynamic GUID-scoped 
    gradient IDs (ld_xxxxxx_*) to eliminate DOM gradient collisions across multi-item lists.
  * Exported static vector asset to wwwroot/images/linkdrop-icon.svg.
  * Replaced all legacy waterdrop SVGs and 'water_drop' font symbols across Navbar, 
    Upgrade, Wallet, Ledger, Packages, Admin Reviews, Creator Earnings, and User Profiles.
- Key Files: Components/Shared/LinkDropIcon.razor, wwwroot/images/linkdrop-icon.svg, 
  LinkDropNavbarBalance.razor, LinkDrops.razor, Upgrade.razor, UserProfile.razor, 
  CreatorEarnings.razor, CreatorPayouts.razor, AdminPlans.razor, AdminLinkDrops.razor, 
  AdminVerifications.razor
- Acceptance Criteria: Unified, responsive, and brand-consistent hexagonal security chip 
  icon rendered on every LinkDrop currency reference throughout the platform.
