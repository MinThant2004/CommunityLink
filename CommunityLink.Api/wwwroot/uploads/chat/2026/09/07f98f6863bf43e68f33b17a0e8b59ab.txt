Description:

-   Discussion with Teammates for Payment & Chat Features Discussed and
    defined the payment-related business requirements and user flows for
    the Community Link project, including:

    -   Payment for Group Chat
    -   Payment for Private Chat
    -   Payment for Link Drop

-   Payment for Link Drop – User Top-Up Flow Defined the user-side Link
    Drop Top-Up and payment request flow, including:

    -   Displaying the user’s current Link Drop balance in the
        navigation bar so that users can easily monitor their available
        Link Drops.
    -   Providing a Link Drop Package selection where users can choose
        from available packages and view the corresponding price and
        Link Drop amount.
    -   Providing a Payment Type / Payment Method selection for users to
        choose their preferred payment channel.
    -   Displaying the total payment amount that the user needs to pay
        based on the selected package.
    -   Providing a Transaction Reference ID field for users to enter
        the transaction ID/reference number from their payment.
    -   Providing an Image Slip / Payment Screenshot Upload feature so
        users can submit payment proof for verification.
    -   Providing a User Note field where users can add additional
        information or notes related to their payment.
    -   Submitting the payment information as a payment request instead
        of immediately crediting Link Drops to the user’s wallet.
    -   Keeping the submitted payment request in Pending status until it
        is reviewed and verified by an Admin.

-   My Purchases & Purchase Details Defined the My Purchases section
    where users can:

    -   View their submitted Link Drop purchase requests.
    -   Check the current payment status such as Pending, Approved, or
        Rejected.
    -   View detailed information for each purchase request.
    -   View the submitted Transaction Reference ID.
    -   View the uploaded payment slip/screenshot.
    -   View additional payment information and Admin remarks/rejection
        reasons where applicable.

-   Wallet & Ledger Defined the Wallet & Ledger section for users to:

    -   View their current Link Drop wallet balance.
    -   View their Link Drop transaction history.
    -   Track Link Drop credits and other wallet transactions.
    -   Review transaction details for better transparency and payment
        tracking.

-   Admin – Link Drops Review Defined the Admin-side Link Drops Review
    management flow, including:

    -   Pending Queue for displaying all user payment requests that are
        waiting for verification.
    -   Admin can open and review individual payment requests.
    -   Admin can check the user’s payment information, selected
        package, payment amount, Transaction Reference ID, uploaded
        payment slip, and user note.
    -   Admin can Approve a valid payment request.
    -   After approval, the corresponding Link Drops are credited to the
        user’s wallet.
    -   Admin can Reject an invalid payment request and provide a
        rejection reason.
    -   Rejected payment requests do not credit Link Drops to the user’s
        wallet.

-   Admin – Packages Catalog Setup Defined the Packages Catalog
    management feature for Admin, allowing Admin to:

    -   Add new Link Drop packages.
    -   Set the package price and Link Drop quantity.
    -   Edit existing package information.
    -   Enable or disable package availability.
    -   Manage the available Link Drop packages displayed to users.

-   Admin – Payment Method Setup Defined the Payment Method Setup
    feature for Admin, allowing Admin to:

    -   Add new payment methods.
    -   Configure payment method information such as payment account
        details and payment instructions.
    -   Edit existing payment method information.
    -   Change the Active / Inactive status of payment methods.
    -   Control which payment methods are currently available for users
        during the Link Drop payment process.

-   Payment Verification Workflow

    Established the overall Link Drop payment workflow as:

    User selects Link Drop Package → Selects Payment Method → Views
    Total Amount → Enters Transaction Reference ID → Uploads Payment
    Slip → Adds User Note → Submits Payment Request → Pending Queue →
    Admin Reviews → Approve / Reject → If Approved, Link Drops are
    credited to User Wallet.
